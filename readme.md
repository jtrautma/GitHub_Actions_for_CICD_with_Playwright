# GitHub Actions for CI/CD with Playwright [Python]

<br>

This repository serves as a *template* on how to set up a CI/CD Process using **GitHub Actions**. The tests to be executed are Playwright tests written in Python using the pytest framework. The test execution is triggered **automatically** when
* there's a `push` to the `Master` branch *or*
* when a Merge Request is created (and then again upon the actual **merge**
